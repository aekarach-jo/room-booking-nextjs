# บทที่ 6: คู่มือการใช้งาน

## 6.1 การเริ่มต้นใช้งาน

### 6.1.1 การเข้าสู่ระบบ

#### วิธีที่ 1: ใช้บัญชีในระบบ
1. เปิดเว็บเบราว์เซอร์และเข้าสู่ `http://localhost:3000/login`
2. กรอกชื่อผู้ใช้และรหัสผ่าน
3. คลิกปุ่ม "เข้าสู่ระบบ"

#### วิธีที่ 2: ใช้ RMUTI SSO
1. คลิกปุ่ม "เข้าสู่ระบบด้วย RMUTI"
2. ระบบจะนำไปยังหน้า Login ของ RMUTI
3. กรอก Username และ Password ของ RMUTI
4. ระบบจะนำกลับมาที่ Dashboard โดยอัตโนมัติ

### 6.1.2 การลงทะเบียน

1. คลิก "สมัครสมาชิก" ที่หน้า Login
2. กรอกข้อมูลดังนี้:
   - **ชื่อผู้ใช้**: ต้องไม่ซ้ำกับผู้อื่น
   - **รหัสผ่าน**: ความยาวอย่างน้อย 6 ตัวอักษร
   - **ชื่อ-นามสกุล**: ชื่อจริง
   - **บทบาท**: เลือกเป็น นักศึกษา/อาจารย์/เจ้าหน้าที่
   - **รหัสนักศึกษา/รหัสอาจารย์**: (ถ้ามี)
   - **ภาควิชา**: ภาควิชาหรือหน่วยงาน
   - **ชั้นปี**: (สำหรับนักศึกษา)
3. คลิก "สมัครสมาชิก"
4. ระบบจะนำไปยังหน้า Login เพื่อเข้าสู่ระบบ

## 6.2 การใช้งานสำหรับนักศึกษา

### 6.2.1 การจองห้อง

#### การจองแบบครั้งเดียว (Single Booking)

1. **ค้นหาห้องที่ต้องการ**
   - ไปที่เมนู "จองห้อง"
   - เลือกประเภทห้อง (ห้องเรียน, ห้องประชุม, ฯลฯ)
   - เลือกอาคาร (ถ้าต้องการ)
   - กรองตามความจุ
   - คลิก "ค้นหา"

2. **ตรวจสอบห้องว่าง**
   - คลิกที่ห้องที่ต้องการ
   - เลือกวันที่
   - ระบบจะแสดงช่วงเวลาที่ว่าง

3. **กรอกข้อมูลการจอง**
   - เลือกวันที่จอง
   - เลือกเวลาเริ่มต้น - เวลาสิ้นสุด
   - กรอกวัตถุประสงค์การจอง (เช่น "ติวเสริม", "ทำโปรเจค")
   - กรอกจำนวนผู้เข้าร่วม (ต้องไม่เกินความจุของห้อง)

4. **ยืนยันการจอง**
   - ตรวจสอบข้อมูลให้ถูกต้อง
   - คลิก "ยืนยันการจอง"
   - รอการอนุมัติจากเจ้าหน้าที่

5. **รับการแจ้งเตือน**
   - เมื่อการจองได้รับการอนุมัติ/ปฏิเสธ ระบบจะแจ้งเตือน
   - ตรวจสอบที่ไอคอนกระดิ่งมุมขวาบน

#### ข้อควรระวัง
- ❌ **ไม่สามารถ**: จองห้องย้อนหลัง (วันที่ผ่านมาแล้ว)
- ❌ **ไม่สามารถ**: จองห้องล่วงหน้าเกิน 7 วัน (ขึ้นอยู่กับนโยบายห้อง)
- ❌ **ไม่สามารถ**: จองติดต่อกันเกิน 3 ชั่วโมง (ขึ้นอยู่กับนโยบายห้อง)
- ⚠️ **ระวัง**: ถ้าไม่มาใช้ห้อง (No-show) ครบ 3 ครั้ง จะถูกระงับการใช้งาน

### 6.2.2 การดูรายการจองของตัวเอง

1. ไปที่เมนู "การจองของฉัน"
2. ระบบแสดงรายการจองทั้งหมด
   - **รอการอนุมัติ** (สีเหลือง)
   - **อนุมัติแล้ว** (สีเขียว)
   - **ปฏิเสธ** (สีแดง)
   - **ยกเลิกแล้ว** (สีเทา)

### 6.2.3 การยกเลิกการจอง

1. ไปที่ "การจองของฉัน"
2. คลิกที่การจองที่ต้องการยกเลิก
3. คลิกปุ่ม "ยกเลิกการจอง"
4. ยืนยันการยกเลิก

**เงื่อนไข**:
- สามารถยกเลิกได้เฉพาะการจองที่ยังไม่เกิดขึ้น
- ควรยกเลิกล่วงหน้าอย่างน้อย 1 ชั่วโมง

### 6.2.4 การ Check-in / Check-out

#### Check-in
1. เมื่อถึงเวลาใช้ห้อง ไปที่ "การจองของฉัน"
2. คลิกที่การจองที่จะใช้
3. คลิกปุ่ม "เช็คอิน"
4. ระบบบันทึกเวลาเข้าใช้

#### Check-out
1. เมื่อใช้ห้องเสร็จ
2. คลิกปุ่ม "เช็คเอาท์"
3. ระบบบันทึกเวลาออก

**หมายเหตุ**:
- ถ้าไม่เช็คอิน หลังเลยเวลาเริ่มต้น 15 นาที = No-show
- No-show ครบ 3 ครั้ง = ระงับการใช้งาน 1 สัปดาห์

### 6.2.5 การดูประกาศ

1. ไปที่หน้า Dashboard
2. ดูประกาศด้านขวา
3. ประกาศจะแบ่งเป็น:
   - **ด่วน** (สีแดง)
   - **คำเตือน** (สีเหลือง)
   - **ข้อมูลทั่วไป** (สีน้ำเงิน)

## 6.3 การใช้งานสำหรับอาจารย์

อาจารย์มีสิทธิ์เหมือนนักศึกษา **บวกกับ**:

### 6.3.1 การจองห้องแบบประจำ (Recurring Booking)

ใช้สำหรับการจองห้องเรียนในแต่ละภาคการศึกษา

1. **เข้าสู่หน้าจองแบบประจำ**
   - ไปที่เมนู "จองแบบประจำ"
   - คลิก "สร้างการจองใหม่"

2. **เลือกห้อง**
   - เลือกห้องที่ต้องการ
   - ตรวจสอบความจุและอุปกรณ์

3. **กำหนดรูปแบบการจอง**
   - **เลือกภาคการศึกษา**: เช่น 1/2567
   - **วันที่เริ่มต้น - วันที่สิ้นสุด**: ตามภาคการศึกษา
   - **รูปแบบ**:
     - **รายวัน (Daily)**: จองทุกวัน
     - **รายสัปดาห์ (Weekly)**: เลือกวันในสัปดาห์ (เช่น จันทร์, พุธ, ศุกร์)
     - **กำหนดเอง (Custom)**: กำหนดวันเอง
   - **เวลา**: เวลาเริ่ม - เวลาสิ้นสุด (ต้องเหมือนกันทุกครั้ง)
   - **วัตถุประสงค์**: เช่น "สอนวิชา Data Structures"

4. **ตรวจสอบความขัดแย้ง**
   - ระบบจะตรวจสอบห้องว่างทุกครั้งที่จอง
   - ถ้ามีความขัดแย้ง จะแจ้งเตือน

5. **ยืนยันการจอง**
   - ระบบจะสร้างการจองทั้งหมดในภาคการศึกษา
   - แสดงจำนวนการจองที่สร้าง

6. **รอการอนุมัติ**
   - เจ้าหน้าที่จะพิจารณาอนุมัติ
   - ถ้าอนุมัติ = การจองทั้งหมดจะอนุมัติพร้อมกัน

**ตัวอย่าง**:
```
ห้อง: 301
ภาคการศึกษา: 1/2567 (1 มิ.ย. - 31 ต.ค.)
รูปแบบ: รายสัปดาห์
วัน: จันทร์, พุธ, ศุกร์
เวลา: 13:00 - 15:00
วัตถุประสงค์: สอนวิชา Data Structures

→ ระบบจะสร้างการจอง ~60 ครั้ง (ประมาณ 20 สัปดาห์ x 3 วัน)
```

## 6.4 การใช้งานสำหรับเจ้าหน้าที่/หัวหน้าภาควิชา

### 6.4.1 การอนุมัติ/ปฏิเสธการจอง

1. **ดูรายการรอการอนุมัติ**
   - ไปที่เมนู "จัดการการจอง"
   - เลือกแท็บ "รอการอนุมัติ"

2. **ตรวจสอบรายละเอียด**
   - คลิกที่การจองเพื่อดูรายละเอียด
   - ดูข้อมูล: ผู้จอง, ห้อง, วันเวลา, วัตถุประสงค์, จำนวนคน

3. **ตัดสินใจ**
   - **อนุมัติ**: คลิก "อนุมัติ" พร้อมระบุหมายเหตุ (ถ้ามี)
   - **ปฏิเสธ**: คลิก "ปฏิเสธ" พร้อมระบุเหตุผล (บังคับ)

4. **แจ้งเตือนผู้จอง**
   - ระบบจะส่งการแจ้งเตือนให้ผู้จองโดยอัตโนมัติ

### 6.4.2 การจัดการห้อง

#### การเพิ่มห้องใหม่

1. ไปที่เมนู "จัดการห้อง"
2. คลิก "เพิ่มห้องใหม่"
3. กรอกข้อมูล:
   - **ชื่อห้อง**: เช่น "ห้อง 301"
   - **ประเภท**: เลือกจาก Dropdown
   - **ชั้น**: เลขชั้น
   - **อาคาร**: ชื่ออาคาร
   - **ความจุ**: จำนวนที่นั่ง
   - **อุปกรณ์**: เช่น โปรเจคเตอร์, ไมค์, แอร์
   - **รายละเอียด**: คำอธิบายเพิ่มเติม
   - **เวลาเปิด-ปิด**: เวลาที่ห้องใช้งานได้
   - **จองสูงสุดกี่ชั่วโมง**: เช่น 3 ชั่วโมง
   - **จองล่วงหน้าได้กี่วัน**: เช่น 7 วัน
   - **ต้องการการอนุมัติหรือไม่**: Yes/No
4. คลิก "บันทึก"

#### การแก้ไขห้อง

1. คลิกที่ห้องที่ต้องการแก้ไข
2. คลิก "แก้ไข"
3. เปลี่ยนข้อมูลที่ต้องการ
4. คลิก "บันทึก"

#### การปิดห้องบำรุงรักษา

1. คลิกที่ห้องที่ต้องการปิด
2. คลิก "บำรุงรักษา"
3. กรอก:
   - วันที่เริ่มปิด
   - วันที่เปิดอีกครั้ง
   - เหตุผล (เช่น "ซ่อมแอร์", "ทาสี")
4. คลิก "บันทึก"
5. ระบบจะแจ้งเตือนผู้ที่มีการจองในช่วงเวลานั้น

### 6.4.3 การจัดการผู้ใช้

#### การดูรายชื่อผู้ใช้

1. ไปที่เมนู "จัดการผู้ใช้"
2. เลือกกรอง:
   - บทบาท: ทั้งหมด/นักศึกษา/อาจารย์/เจ้าหน้าที่
   - สถานะ: ใช้งานอยู่/ระงับ
3. ค้นหาจากชื่อหรือ username

#### การแก้ไขสิทธิ์ผู้ใช้

1. คลิกที่ผู้ใช้ที่ต้องการแก้ไข
2. คลิก "แก้ไข"
3. เปลี่ยนบทบาท (Role) ได้
4. สามารถระงับการใช้งานได้

#### การระงับผู้ใช้ (No-show มากเกินไป)

1. คลิกที่ผู้ใช้
2. คลิก "ระงับการใช้งาน"
3. กำหนดระยะเวลา (เช่น 1 สัปดาห์)
4. ระบุเหตุผล
5. คลิก "ยืนยัน"

### 6.4.4 การจัดการภาคการศึกษา

#### การสร้างภาคการศึกษาใหม่

1. ไปที่เมนู "ภาคการศึกษา"
2. คลิก "เพิ่มภาคการศึกษา"
3. กรอกข้อมูล:
   - **ชื่อ**: เช่น "1/2567"
   - **วันที่เริ่ม**: วันแรกของภาคการศึกษา
   - **วันที่สิ้นสุด**: วันสุดท้ายของภาคการศึกษา
   - **ภาคการศึกษาปัจจุบัน**: Yes/No
4. คลิก "บันทึก"

#### การเพิ่มวันสำคัญ

1. เลือกภาคการศึกษา
2. คลิก "เพิ่มวันสำคัญ"
3. กรอกข้อมูล:
   - **ชื่อ**: เช่น "วันสงกรานต์"
   - **วันที่**: เลือกวันที่
   - **ประเภท**: วันหยุด/วันสอบ/วันกิจกรรม
   - **รายละเอียด**: คำอธิบายเพิ่มเติม
4. คลิก "บันทึก"

**หมายเหตุ**: วันหยุดจะไม่สามารถจองห้องได้

### 6.4.5 การสร้างประกาศ

1. ไปที่เมนู "ประกาศ"
2. คลิก "สร้างประกาศใหม่"
3. กรอกข้อมูล:
   - **หัวข้อ**: ชื่อประกาศ
   - **เนื้อหา**: รายละเอียดประกาศ
   - **ประเภท**: ข้อมูลทั่วไป/คำเตือน/ด่วนมาก
   - **ปักหมุด**: ให้แสดงด้านบนสุดหรือไม่
   - **วันหมดอายุ**: (ถ้ามี) ประกาศจะหายเมื่อถึงวันที่กำหนด
4. คลิก "เผยแพร่"

### 6.4.6 การดูรายงานและสถิติ

#### Dashboard Overview

1. ไปที่ Dashboard
2. ดูสถิติ:
   - จำนวนการจองทั้งหมด
   - จำนวนผู้ใช้
   - จำนวนห้อง
   - การจองที่รอการอนุมัติ
   - การจองวันนี้

#### รายงานการใช้งานห้อง

1. ไปที่เมนู "รายงาน" → "การใช้งานห้อง"
2. เลือกช่วงเวลา (วันเริ่ม - วันสิ้นสุด)
3. ระบบแสดง:
   - จำนวนครั้งที่ถูกจอง
   - จำนวนชั่วโมงรวม
   - อัตราการใช้งาน (%)
4. สามารถส่งออกเป็น CSV ได้

#### รายงานแนวโน้มการจอง

1. ไปที่เมนู "รายงาน" → "แนวโน้มการจอง"
2. ดูกราฟ:
   - จำนวนการจองแต่ละเดือน
   - วันที่มีการจองมากที่สุด
   - ช่วงเวลาที่มีการจองมากที่สุด
   - ประเภทห้องที่ได้รับความนิยม

## 6.5 การตั้งค่าและการใช้งานทั่วไป

### 6.5.1 การเปลี่ยนภาษา

1. คลิกที่ไอคอนธงชาติมุมขวาบน
2. เลือก "ไทย" หรือ "English"
3. ระบบจะเปลี่ยนภาษาทันที

### 6.5.2 การแก้ไขข้อมูลส่วนตัว

1. คลิกที่รูปโปรไฟล์มุมขวาบน
2. เลือก "ข้อมูลส่วนตัว"
3. แก้ไขข้อมูลที่ต้องการ:
   - ชื่อ-นามสกุล
   - อีเมล
   - เบอร์โทรศัพท์
   - แผนก/ภาควิชา
4. คลิก "บันทึก"

### 6.5.3 การเปลี่ยนรหัสผ่าน

1. ไปที่ "ข้อมูลส่วนตัว"
2. คลิก "เปลี่ยนรหัสผ่าน"
3. กรอก:
   - รหัสผ่านเดิม
   - รหัสผ่านใหม่
   - ยืนยันรหัสผ่านใหม่
4. คลิก "บันทึก"

### 6.5.4 การออกจากระบบ

1. คลิกที่รูปโปรไฟล์มุมขวาบน
2. เลือก "ออกจากระบบ"

## 6.6 คำถามที่พบบ่อย (FAQ)

### Q1: ทำไมการจองของฉันถูกปฏิเสธ?
**A**: อาจเนื่องจาก:
- ห้องมีกิจกรรมอื่นแล้ว
- วัตถุประสงค์ไม่เหมาะสม
- ข้อมูลไม่ครบถ้วน
- ละเมิดนโยบายการจอง

ตรวจสอบหมายเหตุจากเจ้าหน้าที่ในรายละเอียดการจอง

### Q2: ถ้าต้องการเปลี่ยนเวลาการจอง ทำอย่างไร?
**A**: 
1. ยกเลิกการจองเดิม
2. สร้างการจองใหม่ด้วยเวลาที่ต้องการ

### Q3: ถ้าห้องที่จองไว้มีปัญหา (เช่น แอร์เสีย) ต้องแจ้งที่ไหน?
**A**: 
- ติดต่อเจ้าหน้าที่โดยตรง หรือ
- แจ้งผ่านระบบประกาศ/แจ้งปัญหา

### Q4: สามารถจองห้องให้คนอื่นได้ไหม?
**A**: ไม่ได้ - ต้องให้เจ้าของบัญชีเป็นคนจองเอง

### Q5: ถ้าลืมเช็คเอาท์ จะเป็นอย่างไร?
**A**: 
- ระบบจะเช็คเอาท์ให้อัตโนมัติเมื่อหมดเวลาจอง
- แต่ควรเช็คเอาท์ทุกครั้งเพื่อความถูกต้อง

### Q6: การจองแบบประจำที่ได้รับการอนุมัติแล้ว สามารถยกเลิกบางครั้งได้ไหม?
**A**: ได้ - ยกเลิกได้ทีละครั้ง ไม่กระทบการจองครั้งอื่น

### Q7: ทำไมฉันไม่สามารถจองห้องได้?
**A**: เช็คว่า:
- บัญชีถูกระงับหรือไม่ (เช็คที่ข้อมูลส่วนตัว)
- มี No-show เกิน 3 ครั้งหรือไม่
- มีการจองที่ทับซ้อนกันหรือไม่

### Q8: ระบบคำนวณ No-show อย่างไร?
**A**: 
- ถ้าไม่เช็คอินภายใน 15 นาทีหลังเวลาเริ่มต้น = No-show
- No-show ครบ 3 ครั้ง = ระงับ 1 สัปดาห์
- No-show ครบ 5 ครั้ง = ระงับ 1 เดือน

## 6.7 Tips การใช้งาน

### สำหรับนักศึกษา
✅ จองล่วงหน้าอย่างน้อย 1 วัน เพื่อให้มีเวลาอนุมัติ  
✅ เช็คอินทุกครั้งเพื่อหลีกเลี่ยง No-show  
✅ ยกเลิกล่วงหน้าถ้ารู้ว่าไม่สามารถมาได้  
✅ ระบุวัตถุประสงค์ที่ชัดเจน เพิ่มโอกาสได้รับการอนุมัติ

### สำหรับอาจารย์
✅ จองแบบประจำตั้งแต่ต้นภาคการศึกษา  
✅ ตรวจสอบความขัดแย้งก่อนยืนยันการจอง  
✅ แจ้งล่วงหน้าถ้าต้องยกเลิกสอน  

### สำหรับเจ้าหน้าที่
✅ ตรวจสอบและอนุมัติการจองอย่างสม่ำเสมอ  
✅ ระบุเหตุผลชัดเจนเมื่อปฏิเสธการจอง  
✅ สร้างประกาศล่วงหน้าสำหรับวันหยุดหรือกิจกรรม  
✅ ตรวจสอบรายงานการใช้งานเป็นประจำ
