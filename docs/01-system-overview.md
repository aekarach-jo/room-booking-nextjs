# บทที่ 1: ภาพรวมของระบบ

## 1.1 ชื่อโครงการ
**ระบบจองห้องเรียนและห้องประชุมออนไลน์สำหรับมหาวิทยาลัยเทคโนโลยีราชมงคล (RMUTI)**  
**Room Booking System for Rajamangala University of Technology Isan**

## 1.2 ที่มาและความสำคัญของโครงการ

### ปัญหาที่พบ
ในปัจจุบัน การจองห้องเรียนและห้องประชุมในสถาบันการศึกษามักประสบปัญหาดังนี้:

1. **การจองแบบ Manual**: การจองผ่านเอกสารหรือการติดต่อแบบพบหน้าทำให้เกิดความล่าช้า
2. **ข้อมูลไม่เป็นปัจจุบัน**: ไม่สามารถตรวจสอบสถานะห้องว่างได้แบบ Real-time
3. **การจัดการที่ซับซ้อน**: เจ้าหน้าที่ต้องจดบันทึกและตรวจสอบการจองด้วยตนเอง
4. **ขาดระบบติดตาม**: ไม่มีระบบแจ้งเตือนและติดตามการใช้งาน
5. **การรายงานที่ไม่มีประสิทธิภาพ**: ยากต่อการสรุปข้อมูลและวิเคราะห์การใช้งาน

### ความสำคัญ
ระบบนี้ช่วยแก้ไขปัญหาดังกล่าวโดย:

- ลดขั้นตอนการจองให้เป็นระบบออนไลน์
- แสดงสถานะห้องว่างแบบ Real-time
- มีระบบอนุมัติอัตโนมัติและการแจ้งเตือน
- สามารถวิเคราะห์ข้อมูลการใช้งานได้
- เชื่อมต่อกับระบบ RMUTI SSO เพื่อความสะดวกในการเข้าสู่ระบบ

## 1.3 วัตถุประสงค์ของโครงการ

1. พัฒนาระบบจองห้องเรียนและห้องประชุมออนไลน์ที่มีประสิทธิภาพ
2. สร้างระบบที่รองรับการใช้งานของผู้ใช้หลายประเภท (นักศึกษา, อาจารย์, เจ้าหน้าที่)
3. พัฒนาระบบที่สามารถจองแบบครั้งเดียวและแบบประจำ (Recurring)
4. สร้างระบบรายงานและวิเคราะห์การใช้งาน
5. เชื่อมต่อกับระบบ Authentication ของ RMUTI (SSO)

## 1.4 ขอบเขตของโครงการ

### ฟังก์ชันหลักของระบบ

#### 1.4.1 ระบบผู้ใช้งาน (User Management)
- ลงทะเบียนและเข้าสู่ระบบ
- เชื่อมต่อกับ RMUTI SSO
- จัดการข้อมูลส่วนตัว
- แบ่งสิทธิ์ผู้ใช้ 4 ระดับ:
  - นักศึกษา (STUDENT)
  - อาจารย์ (TEACHER)
  - เจ้าหน้าที่ (STAFF)
  - หัวหน้าภาควิชา (DEPARTMENT_HEAD)

#### 1.4.2 ระบบจัดการห้อง (Room Management)
- เพิ่ม/แก้ไข/ลบข้อมูลห้อง
- จัดประเภทห้อง (ห้องเรียน, ห้องปฏิบัติการคอมพิวเตอร์, ห้องประชุม, ห้องสมุดกลุ่ม)
- กำหนดอุปกรณ์และความจุของห้อง
- ตั้งค่าเวลาเปิด-ปิดของห้อง
- กำหนดนโยบายการจอง (จองล่วงหน้าได้กี่วัน, จองได้สูงสุดกี่ชั่วโมง)

#### 1.4.3 ระบบจองห้อง (Booking System)
- จองห้องแบบครั้งเดียว (Single Booking)
- จองห้องแบบประจำ (Recurring Booking)
  - รายวัน (Daily)
  - รายสัปดาห์ (Weekly)
  - กำหนดเอง (Custom)
- ตรวจสอบห้องว่าง
- ระบบอนุมัติการจอง
- Check-in/Check-out
- ระบบ No-show tracking

#### 1.4.4 ระบบจัดการภาคการศึกษา (Semester Management)
- สร้างและจัดการภาคการศึกษา
- กำหนดวันสำคัญ (วันหยุด, วันสอบ, วันกิจกรรม)
- เชื่อมโยงการจองกับภาคการศึกษา

#### 1.4.5 ระบบแจ้งเตือน (Notification System)
- แจ้งเตือนการอนุมัติ/ปฏิเสธการจอง
- แจ้งเตือนการจองที่ใกล้ถึงกำหนด
- แจ้งเตือนการบำรุงรักษาห้อง
- ประกาศจากระบบ

#### 1.4.6 ระบบประกาศ (Announcement System)
- สร้างและจัดการประกาศ
- จำแนกประกาศตามความสำคัญ (INFO, WARNING, URGENT)
- ปักหมุดประกาศสำคัญ
- กำหนดวันหมดอายุของประกาศ

#### 1.4.7 ระบบรายงานและวิเคราะห์ (Analytics & Reporting)
- สถิติการใช้งานห้อง
- แนวโน้มการจอง
- รายงานผู้ใช้งาน
- Dashboard สำหรับผู้ดูแลระบบ

### ขอบเขตที่ไม่รวมในโครงการ
- การชำระเงินสำหรับการจอง
- ระบบจัดการอาหารและเครื่องดื่ม
- ระบบ IoT สำหรับการเปิด-ปิดห้องอัตโนมัติ
- Mobile Application (รองรับเฉพาะ Responsive Web)

## 1.5 ผลที่คาดว่าจะได้รับ

1. ระบบจองห้องที่สามารถใช้งานผ่าน Web Browser ได้
2. ระบบที่ลดขั้นตอนและเวลาในการจองห้อง
3. ฐานข้อมูลที่จัดเก็บข้อมูลการจองอย่างเป็นระบบ
4. รายงานและสถิติการใช้งานที่สามารถนำไปวิเคราะห์ได้
5. ระบบที่สามารถนำไปใช้งานจริงในมหาวิทยาลัยได้

## 1.6 เทคโนโลยีที่ใช้พัฒนา

- **React 19**: JavaScript Library สำหรับสร้าง UI

- **Tailwind CSS**: Utility-first CSS Framework

### Backend

- **Prisma ORM**: Database ORM
- **PostgreSQL**: Relational Database
- **JWT (jose)**: Authentication & Authorization
- **bcrypt**: Password Hashing

### Development Tools
- **Git**: Version Control
- **ESLint**: Code Linting
- **Prettier**: Code Formatting
- **Prisma Studio**: Database GUI

## 1.7 สถาปัตยกรรมระบบ

ระบบใช้สถาปัตยกรรมแบบ **Monolithic** โดยรวม Frontend และ Backend ไว้ในโปรเจกต์เดียวกัน:

```
Client (Browser)
      ↓
Next.js Application
      ↓
Prisma ORM
      ↓
PostgreSQL Database
```

### การทำงานของระบบ

1. **Client Side**: ผู้ใช้เข้าถึงระบบผ่าน Web Browser
2. **Server Side Rendering (SSR)**: Next.js render หน้าเว็บบนเซิร์ฟเวอร์
3. **API Routes**: จัดการ Business Logic และเชื่อมต่อกับฐานข้อมูล
4. **Database**: จัดเก็บข้อมูลใน PostgreSQL
